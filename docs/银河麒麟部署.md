# 银河麒麟操作系统（Kylin OS）部署指南（星易查）

适用于银河麒麟桌面操作系统 V10（含 SP1/SP2/SP3）及银河麒麟高级服务器版 V10。
功能与 Windows / macOS / 主流 Linux 桌面版完全一致（含系统托盘角标）。

## 一、第一步：确认 CPU 架构

银河麒麟随 CPU 架构发布不同版本，**请先在终端执行 `uname -m` 确认架构**，再
按对应方式部署：

| `uname -m` 输出 | 典型 CPU | 部署方式 |
|-----------------|----------|----------|
| `x86_64` | Intel / AMD / 海光 / 兆芯 | **专用 .deb 包（第二节，推荐）**，或源码部署 |
| `aarch64` | 飞腾 FT/D 系列 / 鲲鹏 920 / 麒麟 990 | 暂无预编译产物，走源码部署（第六节） |
| `loongarch64` / `mips64` | 龙芯 3A5000/3C5000 等 | 源码部署，OCR 依赖需自行解决（见常见问题） |

## 二、x86_64 麒麟：安装 .deb 专用包（推荐）

**`XingYiCha-kylin-x86_64-<版本号>.deb`** 是为银河麒麟 V10 定制的安装包，
与 Release 里的 AppImage / tar.gz 同源同版本，但针对麒麟做了三项适配：

1. **glibc 兼容**：自带独立 Python 运行时与全部依赖（按 glibc ≥ 2.28 构建），
   麒麟 V10（glibc 2.31）原生可跑——AppImage / tar.gz 构建于 Ubuntu 22.04
   （glibc 2.35），在麒麟上会报 `GLIBC_2.34 not found`；
2. **KYSEC 安全中心自动适配**：安装时自动为可执行文件补可信标签，无需手动
   在安全中心放行；
3. **快装**：payload 单包方案，全程约 1 分钟（避免 dpkg 逐文件处理万级
   文件数的开销）。

安装（终端一条命令，或在文件管理器双击 deb 用麒麟安装器）：

```bash
sudo apt install ./XingYiCha-kylin-x86_64-<版本号>.deb
```

安装内容：`/opt/xingyicha/`（应用与内置运行时）、开始菜单「星易查」入口、
桌面图标风格的 256px 图标、`/usr/bin/xingyicha` 命令。**无需联网**，托盘
依赖的 `python3-gi` / `libappindicator3` 麒麟出厂预装。

### 启动与退出（与 Windows/macOS 版对齐）

- **启动**：开始菜单点「星易查」（无终端窗口，后台静默启动，就绪后自动
  打开浏览器）；已运行时再点一次只是把页面拉起来，不会起第二份服务
- **托盘角标**：任务栏右下角，菜单三项——打开页面 / **打开数据目录** /
  **退出星易查**（退出走这里，或注销/关机）
- **终端排障模式**：命令行 `xingyicha`，终端窗口实时显示日志（关闭窗口即
  停止）；静默模式的日志在 `~/.xingyicha/server.log`
- **数据目录**：`~/.xingyicha/`（uploads 上传原件、history 分析历史、
  server.log 日志）；换机迁移整个目录即可
- **端口**：默认 5001，被占时自动改用 5002-5010；自定义
  `XINGYICHA_PORT=6001` 后从 start.sh / run.sh 启动

### 卸载

```bash
sudo apt remove xingyicha    # 卸载（保留 ~/.xingyicha 用户数据）
sudo apt purge  xingyicha    # 彻底移除
```

> 注：为提速，应用文件不打进 dpkg 数据库（`dpkg -L` 只列少数文件），
> 卸载时由包脚本兜底清理 `/opt/xingyicha`，不影响使用与卸载。

## 三、tar.gz / AppImage（不推荐用于麒麟）

Release 里的 `XingYiCha-linux-x86_64-*.tar.gz` 与 `*.AppImage` 构建于
Ubuntu 22.04（glibc 2.35），**在麒麟 V10（glibc 2.31）上大概率报
`GLIBC_2.34 not found` 无法运行**——这是上游 glibc 版本问题，非安装方式
问题。麒麟机器请优先用第二节的 .deb；确实要用时先 `ldd --version` 确认
本机 glibc ≥ 2.35，并装运行库：

```bash
sudo apt install libgl1 libegl1 libglib2.0-0        # tar.gz
sudo apt install libfuse2                            # AppImage 另需 FUSE
```

## 四、麒麟安全管控（KYSEC）

- **.deb 安装版无需任何手动放行**：postinst 自动调用 `kysec_set` 为全部
  可执行文件（解释器、扩展库、脚本）打 verified 标签
- 手工部署（源码/便携包）被拦截、提示"权限不够"或"未经授权的程序"时：
  1. 「安全中心」→ 应用程序执行控制，将程序所在目录加入可信名单；
  2. 或对具体路径打标签：`sudo kysec_set -r -n exectl -v verified <目录>`；
  3. 临时验证可 `sudo setstatus softmode`（排查用，验证后恢复）
- 开发机注意：KYSEC 会拦截执行**新建的**无标签脚本（含 `python3 - <<EOF`
  读 stdin 脚本）；`kysec_set -n exectl -v verified <文件>` 后即可

## 五、.doc 正文提取（可选依赖）

.deb 包已内置 antiword（含映射文件），`.doc` 正文提取开箱即用。如需更优的
复杂排版转换效果可加装 LibreOffice（WPS 不可替代）：

```bash
sudo apt install libreoffice
```

程序探测顺序 LibreOffice 优先；识别不到时设
`SOFFICE_PATH=/opt/libreoffice25.2/program/soffice` 后重启。启动日志会打印
实际识别到的转换器路径（`--check` 亦然）。

## 六、离线（内网）安装

`.deb` 包本身就是离线安装包（依赖仅 curl / xdg-utils，麒麟出厂自带）。
内网机器：联网机下载 deb → U 盘拷贝 → `sudo apt install ./xxx.deb`，全程
不联外网。AppImage / tar.gz 路线的三个系统库同理用 `apt download` 预取。

## 七、aarch64（飞腾/鲲鹏）与其他架构：源码部署

预编译产物当前仅 x86_64。飞腾/鲲鹏等 ARM 机器按以下步骤部署（麒麟 V10 自带
Python 3.8 一般可用；若 `pip install` 装不上依赖——新版 PyMuPDF 等常要求
≥3.9——从麒麟软件源安装 Python 3.11 后用它建 venv。依赖 PyMuPDF、
onnxruntime 等均提供 aarch64 Linux 轮子）：

```bash
# 1. 安装基础工具（未预装时）
sudo apt install python3 python3-venv python3-pip

# 2. 获取源码（git 或直接下载源码包拷贝进内网）
git clone git@github.com:yjiao286/xingyicha-bid-rigging-detection.git
cd xingyicha-bid-rigging-detection

# 3. 创建虚拟环境并安装依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 4. 启动
python3 app.py 5001
```

启动后浏览器访问 `http://<机器IP>:5001`（局域网使用需放开防火墙对应端口，
或将启动命令改为 `HOST=0.0.0.0 python3 app.py 5001`）。

**常驻运行**（服务器/多人共用场景）：

```bash
nohup ./venv/bin/python3 app.py 5001 >/var/log/xingyicha.log 2>&1 &
```

或编写 systemd 服务单元开机自启；生产模式也可使用仓库根目录 `Dockerfile` +
`docker-compose.yml`（麒麟服务器版支持 Docker）。

x86_64 机器也可在麒麟上**从源码自行构建 .deb**（打包脚本已内置镜像回退，
构建机需联网一次；Release 里的 deb 由 CI 用同一脚本自动构建，仅在需要
自定义或离线环境时才需自建）：

```bash
./packaging/linux-deb/build-deb.sh        # 产物 dist/xingyicha_<版本>_amd64.deb
```

## 八、常见问题

- **报 `GLIBC_2.xx not found`**：用的是 tar.gz/AppImage（glibc 2.35 构建），
  麒麟请改用 .deb（第二节）或源码部署
- **报 `libGL.so.1: cannot open shared object file`**：tar.gz/AppImage 路线
  `sudo apt install libgl1`；.deb 不需要
- **安装慢 / 卡在 95%**：v3.1.0-3 起的 payload 方案约 1 分钟装完；个别
  机器 KYSEC 处理慢时请耐心等 postinst 完成，不要强杀 dpkg
- **程序被安全管控拦截**：见第四节
- **托盘角标不出现**：确认 `python3-gi`、`gir1.2-appindicator3-0.1`、
  `libappindicator3-1` 已装（麒麟预装；`sudo apt install python3-gi
  python3-gi-cairo gir1.2-appindicator3-0.1`）；应用本体不受影响，
  可用终端模式 `xingyicha` 排障
- **龙芯（loongarch64）机器**：onnxruntime 无官方 LoongArch 轮子，RapidOCR
  装不上时属预期——OCR 为可选依赖，缺失时扫描件 PDF 自动跳过，其余功能完整；
  如需 OCR 可从麒麟软件源寻找 onnxruntime loongarch 移植包
- **端口占用**：自动改用 5002-5010，以终端打印的实际地址为准
- **机器配置低 / 扫描件太大跑不动**：用环境变量给 OCR 封顶
  （`OCR_MAX_PAGES=50`、`OCR_TIME_BUDGET=120`，终端启动时前缀或 systemd 单元
  里加 `Environment=` 行），完整调优参数表见
  [硬件配置要求](硬件配置要求.md)第七节
- **上传文件 / 历史记录在哪**：.deb 安装版在 `~/.xingyicha/`；换机迁移整个
  目录
